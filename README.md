# 小鱼岛

macOS 刘海（灵动岛）效率工具。当前先发测试版，方便下载体验。

## 下载

[**下载 v1.0.0-test.2（Apple Silicon）**](https://github.com/anzhiyu-c/xiaoyu-dao/releases/download/v1.0.0-test.2/XiaoyuDao-1.0.0-test.2-macos-arm64.zip)

需要 macOS 14+，仅支持 Apple Silicon（M 系列）。发布页：[Releases](https://github.com/anzhiyu-c/xiaoyu-dao/releases/tag/v1.0.0-test.2)

## 安装

1. 下载 `XiaoyuDao-1.0.0-test.2-macos-arm64.zip` 并解压
2. 把「小鱼岛」拖进「应用程序」文件夹
3. 打开应用

如果系统提示无法验证开发者：

- 在访达里 **右键点「小鱼岛」→ 打开 → 仍要打开**
- 或打开 **系统设置 → 隐私与安全性**，滑到下方点 **仍要打开**

首次使用截图、划词翻译、天气、镜子等功能时，系统会要屏幕录制、辅助功能、定位、摄像头等权限，按提示授权即可。
